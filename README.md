# Meadway interactive model

An interactive architectural study of 21 Meadway, with terrain, two floor plans, a section view and 19 selected roof trusses. English labels include Chinese translations. The separately delivered 30-second silent film uses the same model.

- Desktop: drag to orbit, scroll to zoom, right-drag to pan.
- Mobile: one finger to orbit, two fingers to zoom or pan; tap to inspect a component. Scroll outside the model to reach controls.
- Select a view, hide the roof, or inspect existing component properties.

This is an architectural visualization, not a structural design. Foundations are not designed. Platforms and the source drawings' 100 mm level conflict remain identified in the viewer. Only S2 (nine) and S4 (ten) trusses are included; other truss types are omitted. Bearing heights and gutter setdown remain schematic. Displayed component extents are model bounding boxes, not design sections.

Only the static viewer and derived model data are included. Original PDF/DWG files, credentials, local paths and development logs are excluded. Model assets are publicly downloadable.

## Hosting

GitHub Pages serves the main branch root. All runtime assets are local and use relative paths. Serve over HTTP(S); opening index.html through file:// is unsupported.
