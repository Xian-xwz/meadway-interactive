## 本次具体算了什么

S2 原页为 Lots 1–3 PS1 第7页，Job J030073-Lot1-3，17 Sep 2026。图示两个竖向支座间 5180 mm，L1 沿底弦；采用 PS1 的900 mm设计分担宽。按两端不传弯矩的外部竖向静力平衡模型，复用中央 `_reaction`。它只求外部反力，不代表屋架弦杆、腹杆或节点板的验算。

| 已知作用 | 输入 | S2外端特征反力 |
| --- | --- | --- |
| L1天花面层，支座间全跨 | 12.7 kg/m² × 9.81 /1000 ×0.9 = 0.1121283 kN/m | 0.2904123 kN |
| 房屋屋面分布活载，仅支座间范围 | 0.25 kPa ×0.9 =0.225 kN/m | 0.58275 kN |
| 房屋屋面集中活载，在外支座处的不利位置 | 1.1 kN；与分布活载分开检查 | 1.1 kN |
| 底弦人员荷载，独立检查项 | 1.4 kN；未擅自采用0.9 kN折减 | 1.4 kN |

活载依据：AS/NZS1170.1:2002 Table3.2 Note3、§3.5.2，物理第17页。1.1 kN不能当作kPa，也不能与0.25 kPa全额叠加；底弦人员荷载没有冒充屋面活载送入中央模块。挑檐贡献及实际传力分配还需补齐。
